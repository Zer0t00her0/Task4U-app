Подключение к GitHub

Доска читает и пишет файлы прямо в репозиторий. Токен хранится только в этом браузере.

Это превью. Здесь работает только демо, всё сохраняется в твоём браузере. Подключение к GitHub заработает на версии из репозитория.

Открыть на другом устройстве

Открой эту ссылку на другом компьютере или наведи камеру телефона на QR-код — доска подключится сама, токен вводить не нужно. В ссылке зашит твой токен: отправляй её только себе (например, в «Избранное» мессенджера) и удали после входа.
